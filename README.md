# Customer Churn Prediction Using Machine Learning

## Project Overview

This project predicts whether a customer may leave a service using a Random Forest machine learning model.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* Streamlit

## Features

* Displays sample customer data.
* Trains a Random Forest classification model.
* Displays test accuracy.
* Accepts customer information.
* Predicts customer churn and estimated probability.
* Displays churn distribution and feature importance charts.

## How to Run

1. Install Python.

2. Install the required libraries:

   ```bash
   python -m pip install pandas scikit-learn streamlit
   ```

3. Run the application:

   ```bash
   python -m streamlit run app.py
   ```

4. Open the local URL shown in your terminal.

## Dataset

This project uses a small synthetic dataset created for educational purposes. Its predictions and accuracy are illustrative and should not be treated as reliable real-world performance.
